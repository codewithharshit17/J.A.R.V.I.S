# J.A.R.V.I.S - Full Stack AI Vision Assistant

J.A.R.V.I.S is a futuristic full-stack AI assistant inspired by Iron Man's JARVIS system.

The project combines:

- Modern frontend engineering
- Real-time communication
- Computer vision
- Voice AI
- LLM orchestration
- Automation systems
- AI-first dashboard architecture

The goal is to build a scalable multimodal AI system capable of:

- Seeing through webcam input
- Understanding voice commands
- Responding intelligently
- Performing automation tasks
- Operating through a futuristic dashboard interface

---

## Project Vision

J.A.R.V.I.S is not just a chatbot.

It is being engineered as a:

- Realtime AI Operating System
- Multimodal AI Assistant
- Full Stack AI Platform
- Future AI Agent Architecture

The system is designed with long-term scalability in mind so future upgrades can be integrated cleanly, including:

- Local LLMs
- Memory systems
- Multi-agent workflows
- GPU processing
- Smart automation

## Setup

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
python -m venv venv
```

#### Windows

```bash
venv\Scripts\activate
```

#### macOS / Linux

```bash
source venv/bin/activate
```

### Run Backend Server

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```
